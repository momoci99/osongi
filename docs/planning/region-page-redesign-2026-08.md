# 지역 허브(/region) 재설계 — 2026-08

`docs/planning/region-page-design-fix.md`(결함 16건 수정) 이후에도 남은 **구조적** 문제를 다룬다.
직전 문서는 개별 결함(간격·색·문구)을 고쳤고, 이 문서는 **정보 구조와 시각적 인코딩**을 바꾼다.

## 1. 진단

데스크톱 1440 / 모바일 390, 다크 테마 스크린샷 기준.

### 1-1. 정렬 기준이 시각적으로 가장 약하다 (최우선)

섹션 제목은 "산림조합 (최신 시즌 물량순)"인데, 정렬 키인 공판량(`18.0톤`)이
12px 회색 caption으로 카드 맨 아래에 있다. 카드 20장은 크기·색·굵기가 모두 동일하다.
순위 번호도, 크기 비교를 위한 막대도 없다.

→ "물량순"이라는 사실을 **제목 텍스트를 읽어야만** 알 수 있다. 데이터 대시보드인데
   시각적 인코딩이 사실상 0이고, 결과적으로 20장이 균일한 벽지처럼 보인다.

### 1-2. 지역 카드 우측 절반이 죽은 면적

카드 폭 약 440px 중 콘텐츠는 왼쪽 200px만 사용한다. 3장이면 660px가 빈다.
페이지 전체로는 콘텐츠가 3450px 중 1400px에서 끝나고 푸터까지 공백이 남는다.

### 1-3. 타이포 위계 역전

| 요소 | 크기 |
|---|---|
| h1 | 30px |
| 본문 | 14px |
| 섹션 h2 | **16px** |
| 지역 카드 이름 | **20px** |

섹션 제목이 자식 요소보다 작다. 본문(14px)과도 2px 차이라 섹션 경계가 읽히지 않는다.
구분선도 지역/조합 사이 1개뿐이라 리듬이 없다.

### 1-4. 값 표기 불일치

- 지역 카드: `188,276` 크게 + `원/kg` 작게
- 조합 카드: `평균 189,902원/kg` 한 덩어리 12px

같은 지표를 두 가지 형식으로 쓴다. `80.4톤`에는 라벨이 없어 무슨 숫자인지 알 수 없다.

### 1-5. 중복 인코딩과 정렬 어긋남

조합 카드에 지역 색 도트와 "경북" 텍스트가 함께 있다(같은 정보 2회).
도트의 `alignItems: center`가 이름+note 블록 전체를 기준으로 잡혀
이름 baseline보다 아래로 내려가 걸친다. (`ScopeLinkGrid.tsx:96-108`)

### 1-6. 헤더 하이라이트가 고립

"최신 시즌 최고 단가" 칩 한 줄이 다른 요소와 연결 없이 떠 있다.
링크지만 밑줄·색 강조가 없어 클릭 가능 신호가 없다. (`RegionIndex.tsx:72-79`)

### 1-7. 모바일 5630px 스크롤

조합 20행 전부 우측 12px 회색 2줄. 판독 불가.
카드 테두리 20개가 노이즈로 쌓인다.

### 1-8. 기타

- 색이 정보를 나르지 않는다. 화면 전체에서 색은 8px 도트 3색 + 초록 칩뿐
- `&:hover`만 있고 `&:focus-visible`이 없어 키보드 포커스가 사라진다
- 21개 조합인데 필터·검색·정렬 전환이 없다. 찾는 방법이 눈 스캔뿐
- "최신 시즌 집계 없음" 영천이 컨테이너 없이 페이지 끝에 매달린다

## 2. 개선 방향

### P0-A. 조합 목록: 카드 그리드 → 랭크 리스트

```
 1  ▮ 영덕  경북   ████████████░░  18.0t          189,902 원/kg
 2  ▮ 문경  경북   ██████████░░░░  15.0t          169,641 원/kg
```

- 순위 번호(tabular-nums) + 지역 색 도트 + 이름 + **공판량 막대** + 단가
- 막대 폭 = 해당 조합 물량 / 목록 최대 물량. 정렬 기준을 눈으로 즉시 읽게 한다
- 단가는 15px semibold `text.primary`로 승격 (기존 12px 회색 → 판독 불가 해소)
- 카드 테두리 20개 제거. 행 구분은 hairline + hover 배경
- 모바일도 같은 행 구조를 압축해 재사용 → 높이 5630 → 약 3000px

`ScopeLinkGrid`는 상세 페이지에서도 쓰이므로 `ScopeRankList`로 교체하고
델타 배지(`compareToPricePerKg`) 기능은 그대로 승계한다.

### P0-B. 타이포 스케일 재정의

| 요소 | 변경 후 |
|---|---|
| 섹션 h2 | 1.125rem / 700 / `letterSpacing .01em` / 상단 여백 40px |
| 카드·행 이름 | 1rem |
| 값 | 0.9375rem semibold `text.primary` |
| 단위·라벨 | 0.75rem `text.secondary` |

섹션 제목이 항상 자식보다 크도록 고정한다.

### P1-A. 지역 카드 우측에 스파크라인

오른쪽 죽은 면적에 연도별 평균 단가 스파크라인(D3, 인라인 SVG)을 넣는다.
`manifest.regions[*].yearly`를 그대로 쓴다. 카드가 "요약"으로 승격되고 공백이 사라진다.

### P1-B. 헤더 칩 → KPI 3칸

칩 한 줄을 `ScopeKpiCard` 3칸으로 승격한다.

- 최고 단가 조합 (강원 양양 275,351원)
- 전체 공판량 (121.6톤)
- 기준일 (2025-11-12)

### P1-C. 필터·정렬 컨트롤

지역 칩 행(전체/강원/경북/경남) + 정렬 토글(물량순 ↔ 단가순).
21행 목록에는 필수. 상태는 페이지 로컬 `useState`.

### P2. 잔결함

- `평균` 접두 제거, 지역·조합 값 표기 형식 통일
- 톤 값에 `공판량` 라벨
- 도트를 이름 Typography와 같은 flex 행으로 이동해 baseline 정렬
- 도트가 있으면 지역 텍스트 중복 제거 (모바일 좁은 폭에서만 유지)
- 집계 없는 조합(영천)은 목록 마지막에 `opacity .5` 행으로 편입, 별도 블록 삭제
- 전 인터랙티브 요소에 `&:focus-visible` 아웃라인

## 4. 성공 기준

- 조합 목록을 제목 없이 봐도 정렬 기준이 읽힌다
- 데스크톱 1440에서 푸터 위 빈 영역이 사라진다
- 모바일 문서 높이 5630px → 3500px 이하
- 섹션 제목이 항상 하위 요소보다 크다
- 키보드 Tab으로 모든 링크에 포커스 링이 보인다

## 5. 적용 결과 (2026-08-12)

전 항목 구현 완료. 실제 파일은 3절 계획과 같고, 스파크라인 경로 계산만
`src/utils/d3/sparkPath.ts`로 분리했다 (컴포넌트 파일이 함수를 함께 내보내면
Fast Refresh가 깨진다는 `react-refresh/only-export-components` 경고).

계획에 없던 추가 정리:

- `ScopeGradeTable`·`ScopeYearlyChart`의 16px 제목도 `ScopeSectionHeading`으로 통일.
  상세 페이지 안에서 새 랭크 리스트 제목만 18px이라 위계가 다시 어긋나 있었다
- 상세 페이지의 `Divider`는 제거. 섹션 상단 여백(40px)이 같은 역할을 한다
- 막대 열에 480px 상한. 상한이 없으면 1440 화면에서 6px 높이 막대가 600px까지
  늘어나 실처럼 보인다. 남는 폭은 톤 열이 흡수한다

측정값 (fullPage, CSS px):

| 화면 | 이전 | 이후 |
|---|---|---|
| 데스크톱 1440 문서 높이 | 1725 | 2237 |
| 데스크톱 콘텐츠 종료 → 푸터 공백 | 약 300 | 약 120 |
| 모바일 390 문서 높이 | 2815 | 2622 |

데스크톱 문서가 길어진 것은 의도한 결과다. 카드 20장이 4열로 압축돼 있던 것을
21행 리스트로 폈고, 그 대신 빈 화면과 판독 불가능한 12px 회색 값이 사라졌다.
