## 2. 적용

### 막대가 정렬 기준을 따라간다 (A1·A2·A4)

막대는 이제 **현재 정렬 키**를 그린다. 물량순이면 공판량, 단가순이면 단가다.
열 머리글도 `UNION_METRIC_HEADERS` 로 함께 바뀐다.
제목을 읽지 않아도 목록이 무엇으로 줄 세워졌는지 눈으로 확인된다.

단가는 0부터 그리면 16만~28만이 전부 60% 넘게 차 차이가 사라진다.
목록의 **최저~최고를 축으로 잡는 range bar** 로 그리고, 머리글에 범위를 밝힌다.

두께 6 → 10px, 폭은 상한(480px) 대신 이름 열과 `1 : 2.2` 로 나눠 갖는다.
지역 상세 목록에는 **지역 평균 대비 단가 델타**를 붙였다. 같은 지역이라 막대 색이
정보를 나르지 못하던 자리를 델타 색(`chart.up` / `chart.down`)이 대신한다.

### 지표 패널 (B2·B4·C4)

KPI 카드 가로 배치를 버리고 `ScopeStatPanel` 세로 패널로 바꿔 **제목·요약 문단 옆에 세운다**
(`ScopeHero`, md 이상 2단). 카드 안 죽은 면적, 문단 오른쪽 공백, 모바일 2+1 배치가
한 번에 정리된다. 좁은 화면에서는 문단 아래로 떨어진다.

허브 hero에는 데이터 출처·갱신 주기 문단을 한 단락 더 넣어 좌우 높이를 맞췄다.

### 그 외

- 필터 칩 + 정렬 토글을 목록 위 한 줄에서 좌우로 맞물림 (B1)
- 필터 칩에 지역 색 도트 → 목록 도트의 범례를 겸함 (C2 보완)
- 등급표 비중 막대 `TABLE_MAX_WIDTH: 120` 상한 (B3)
- 모바일 행 배경 틴트 → **행 하단 3px 스트립**(`&::after`). 글자와 겹치지 않는다 (C1)
- 모바일에서도 지역명 노출 (C2), 지역 카드 스파크라인 축소 표시 (C3)
- 모바일 단가 열 86 → 116px, 톤 열 52 → 44px (C5)
- 요약 문단 15px / 행간 1.8 / 62ch — 14px가 68ch로 흐르면 줄이 길어 다음 줄을 놓친다

### 지표 패널 수치 정렬 (실물 확인 후 추가 수정)

패널을 세운 뒤 실물에서 세 가지가 더 걸렸다.

| 증상 | 원인 | 조치 |
|---|---|---|
| 행마다 숫자 오른쪽 끝이 어긋남 | 단위를 값 뒤에 그냥 붙여 `원/kg`·`톤`·단위 없음이 섞이면 숫자가 끝나는 위치가 달라진다 | 단위를 고정 폭 40px 열로 분리(`SCOPE_STAT_PANEL.UNIT_WIDTH`). 단위 없는 행도 열을 비워 기준선 유지 |
| 숫자가 위로 떠 보임 | `alignItems: baseline` 이 라벨 **첫 줄**에만 맞아 캡션 높이만큼 아래가 빈다 | 행 정렬을 `center` 로 바꿔 라벨+캡션 두 줄 블록의 세로 가운데에 맞춤 |
| 값과 캡션이 붙음 | 간격 12px + `산림조합중앙회 공판 실적` 캡션이 길어 292px 콘텐츠 폭에서 충돌 | 간격 20px, 캡션은 `공판 실적 기준` 으로 축약(출처는 푸터에 있음) |
