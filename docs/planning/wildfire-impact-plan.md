# 산불 영향 분석 기획 (초안)

작성 2026-09-26 · 브랜치 `feat/wildfire-impact`

## 1. 목적

큰 산불이 송이 주산지의 공판 물량을 얼마나, 얼마나 오래 줄이는지 **사실로 보여 준다.**

## 2. 도메인 배경

- 송이는 살아 있는 소나무 뿌리와 공생한다. **소나무 군락지에 불이 나면 송이가 나는 면적 자체가 줄어든다** (사용자 현장 지식, 2026-09-26)
- 날씨는 며칠~몇 주 단위로 물량을 흔들지만, 산불은 **수년~수십 년** 단위의 계단식 감소를 만든다 → 분석 단위는 조합 × 시즌
- 한계: 군 전체 산림 중 실제 탄 부분, 그중 소나무 군락 비율은 모른다(임상도 GIS 없이는)

## 3. 자료

### 3-1. 산림청 산불발생통계 API (공공데이터포털 3070842)

- `npm run collect-wildfire` → `data/wildfire/raw/{year}.json` (이용 제한 없음, git 추적)
- 제공 범위 **2011~현재** (2010 이전 0건 — 2026-09-26 확인). 연 200~760건
- 필드: 발생·진화 일시, 시도·시군구·읍면·동리, 원인, 피해면적(ha)
- ⚠️ **위치는 발화 지점 하나뿐.** 여러 시군으로 번진 대형 산불도 발화 시군에만 기록된다
  - 예: 2025 경북 산불은 API 에 "의성" 두 건(52,707ha + 46,575ha)으로만 있음 — 실제로는 안동·청송·영양·영덕까지 탔다

- 원칙: 공식 발표(산림청·정책브리핑)만 쓴다. 2차 자료는 확인 전까지 "잠정" 표기
- 번지지 않은 산불(대부분)은 API 발화 시군 그대로

### 3-3. 필요하지만 아직 없는 자료

- **시군별 산림 면적** — 피해를 "군 산림의 몇 %" 로 환산하기 위함 (산림청 임업통계연보)

## 5. 분석·표시 방향 (제안)

| 단계 | 내용 | 게이트 |
|---|---|---|
| F-V1 사실 표시 ✅ (09-26) | 지역·조합 페이지 연도별 공판 추이 차트에 산불 표식 — 불난 뒤 첫 시즌 막대 왼쪽 경계 점선, 머리 점 크기는 피해 규모(로그), 차트 아래 산불 목록. `npm run generate-wildfire-stats` → `public/wildfire/union-fires.json` | 불필요 — 사실 |
| F-A1 전후 비교 | 산불 전 N시즌 평균 대비 이후 시즌 공판량 비율을, 같은 기간 산불 없는 조합의 비율과 비교 (이중차분) | 사건 수가 적어 **상관·유의성 판정 없이 서술만** (기존 원칙: 시즌 단위 표본은 서술만) |

- 비교 기준(몇 시즌 전 평균, 피해 규모 문턱)은 **분석 전에 고정**한다 (날씨 분석과 같은 방식)

### 5-1. 결정 (2026-09-26)

- **F-A1 전후 비교는 하지 않는다.** 해마다 물량 변동이 커서 산불 효과를 가려내기 어렵고, 해석할 만한 사례가 적다(울진 2022, 경북 2025 정도)
- 산불 기능은 **"이 지역에 대형 산불이 있었다"를 알리는 UI 까지** — F-V1 로 완료
