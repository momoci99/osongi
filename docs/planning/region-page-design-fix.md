# 지역·조합 페이지 디자인 수정 작업서

> 대상: `/region`, `/region/:region`, `/region/:region/:union`
> 근거: [`roadmap-2026-08.md`](./roadmap-2026-08.md) 2장 (P0)
> 확인 환경: 데스크톱 1280×900 / 모바일 390×844, 다크 테마
> 착수 2026-08-11

---

## 원칙

1. **모바일 우선.** 타깃(채취자·농가)이 산지에서 모바일로 본다. 데스크톱은 그 다음.
2. **SEO 텍스트를 지우지 않는다.** 요약 문단은 색인 자산이다. 화면에서 접되 DOM·프리렌더 HTML에는 남긴다.
3. **프리렌더 동기화.** 컴포넌트 스타일을 바꾸면 `scripts/prerenderStyle.ts`·`scripts/prerender-scope-pages.ts`를 같은 커밋에서 맞춘다. 어긋나면 hydration 시 레이아웃이 튄다.
4. 차트는 D3 직접 구현 유지. 래핑 라이브러리로 바꾸지 않는다.
5. 매직 넘버는 `src/const/Charts.ts` 등 상수 파일로.

## A. 모바일 치명 (M1~M4) 🔴

### M1. 등급표 텍스트 붕괴 — `ScopeGradeTable.tsx`

**현상**: 390px에서 `3등품(생장정지품)`이 한 글자씩 세로 7줄로 쪼개짐. 헤더 `평균 단가 (원/kg)`도 3줄.
4열 표(등급·단가·물량·비중)가 좁은 폭에 강제로 들어가며 모든 셀이 세로 압축됨.

**수정**: 브레이크포인트로 표현을 분기한다.
- `xs`: 표 대신 **등급 카드 리스트** — 행마다 좌측에 등급 색 도트 + 등급명, 우측에 단가(굵게), 하단에 물량·비중 막대
- `sm↑`: 현행 표 유지 + D1·D2 반영

**완료 기준**: 390px에서 어떤 텍스트도 두 줄 이상 깨지지 않는다.

### M2. KPI 숫자 줄바꿈 — `ScopeKpiRow.tsx`

**현상**: `192,427원`이 `192,427` / `원`으로 분리. `732,600원`도 동일.

**수정**: 값과 단위를 분리해 값에 `white-space: nowrap`, 폰트 크기를 `clamp()`로 반응형 축소. 단위(`원`, `톤`)는 값보다 작은 크기로 붙인다.

**완료 기준**: 390px 2×2 배치에서 네 칸 모두 값이 한 줄.

### M3. 차트가 모바일에서 판독 불가 — `ScopeYearlyChart/useDrawYearlyTrend.ts`

**현상**: 좌우 y축 2개가 폭을 잠식해 막대 폭이 6px 수준. x축은 격년만 표시.

**수정**: `isMobileWidth`일 때
- 오른쪽 가격 축 눈금 라벨 생략(선은 유지, 값은 툴팁으로)
- 좌우 마진 축소
- 막대 최소 폭 확보. 확보 불가하면 가로 스크롤 컨테이너로 전환

**완료 기준**: 390px에서 막대가 식별 가능하고 축 라벨이 겹치지 않는다.

### M4. 링크 카드 눌림 — `ScopeLinkGrid.tsx`

**현상**: `xs=6` 2열에서 조합명·단가·톤 3줄이 좁은 칸에 눌림.

**수정**: `xs`에서 1열 **리스트 행** 레이아웃(좌: 조합명, 우: 단가·물량 우측 정렬). `sm↑`는 카드 그리드 유지.

## B. 정보 위계 (H1~H6) 🟠

### H1. 요약 문단이 KPI를 밀어냄 — `ScopeHeader.tsx`

**현상**: 문단 4개가 데스크톱 첫 화면의 절반, 모바일 한 화면 전체를 차지. 지표를 보려면 스크롤해야 함.

**수정**: 첫 문단만 노출, 나머지는 "자세히" 토글로 접는다. 접힌 내용도 DOM에 존재해야 한다(색인 자산). KPI를 문단보다 위로 올리는 배치도 함께 검토.

**주의**: 프리렌더 HTML에서는 전문이 펼쳐진 상태로 나가야 크롤러가 읽는다.

### H2. 허브에서 지역·조합 카드가 동일 — `RegionIndex.tsx`

**현상**: 지역 카드 3개와 조합 카드 21개가 완전히 같은 스타일·크기 → 위계 없음. `경북 (조합 13곳)`이라는 이름 문자열 조합도 어색.

**수정**: 지역은 큰 카드(지역명 대형 + 조합 수 + 대표 지표 + 지역 색), 조합은 조밀한 리스트. 두 섹션의 시각 밀도를 다르게 한다.

### H3. 조합 21개 평면 나열 — `RegionIndex.tsx`

**현상**: 지역 구분 없이 물량순 나열. `REGION_BASE_HUES` 상수가 존재하는데 쓰이지 않음.

**수정**: 조합 항목에 지역 색 도트 + 지역 라벨. 지역 필터 칩(전체/강원/경북/경남) 추가 검토.

### H4. 상세 하단이 허브와 구분되지 않음 — `RegionDetail.tsx`

**현상**: "경북의 다른 조합 시세"가 허브와 같은 컴포넌트·같은 밀도라 두 페이지가 같아 보임.

**수정**: 상세에서는 **현재 조합 대비 단가 차이(±%)** 를 넣은 컴팩트 리스트로 전환. 비교 맥락이 생기면 내부 링크의 클릭 이유도 생긴다.

### H5. 섹션 리듬 단조 — 공통

**현상**: 모든 섹션이 `h2 + 카드` 한 패턴. 데스크톱 1280에서 여백 과다.

**수정**: 첫 화면에 KPI+차트를 묶고, 표·링크는 밀도를 높인다. 섹션 간 여백을 차등 적용.

### H6. 허브 하단 빈 공간 — `RegionIndex.tsx`

**현상**: 콘텐츠가 짧아 푸터 위가 비어 보임.

**수정**: 최신 공판일 하이라이트(최고 단가 조합 등) 한 줄 추가로 콘텐츠 보강 겸 해결.

| M3 | 모바일에서 가격 축 라벨 접고 여백 회수, 막대 최소 폭 미달 시 가로 스크롤 |

### 남은 것
- 델타 배지 색이 파랑/회색이라 "비쌈·쌈"이 색으로는 직관적이지 않음. 등급 색과 충돌을 피하려 채도를 낮춘 결과 — 시즌 데이터로 재판단
- 상세 페이지 하단 여백은 여전히 넉넉함. 콘텐츠가 늘면 자연 해소
