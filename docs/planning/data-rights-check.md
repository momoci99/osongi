## 2. 상세

### 2-1. robots.txt ✅

`https://iforest.nfcf.or.kr/robots.txt` 전문:

```
User-agent: *
Disallow: /cyber/
Disallow: /wnlvldpadptm/
Disallow: /upload/
Disallow: /mvisit/
Disallow: /morder/
Allow: /
```

수집 대상 경로는 `/forest/user.tdf` 이며 **Disallow 목록에 해당하지 않는다.**
`mc=CYB_FIF_DGS_SNI` 의 `CYB` 는 쿼리 파라미터 값일 뿐 경로가 아니므로 `/cyber/` 금지와 무관하다.

→ robots.txt 관점에서는 현재 수집이 규약 위반이 아니다.

### 2-2. 이용약관 ✅ (전문 확인 완료, 시행일 2008-01-21)

**핵심: 이것은 회원 약관이며, 오송이는 약관의 당사자가 아니다.**

| 조항 | 내용 | 해석 |
|------|------|------|
| 제2조 | "귀하가 본 약관 내용에 **동의하는 경우** ... 우선적으로 적용" | 동의(가입)를 효력 발생 요건으로 명시 |
| 제4조 | "이용자: **본 약관에 따라** 서비스를 받는 자" / "회원: 개인정보를 제공하여 회원 등록을 한 자" | 정의 자체가 가입을 전제 |
| 제5조 | "이용계약은 ... 가입신청 양식을 기록하여 **가입을 완료하는 것으로 성립**" | 계약 성립 시점 = 가입 |

오송이는 **로그인 없이 공개 페이지를 열람**한다. 가입·동의가 없으므로 이용계약이 성립하지 않고, 약관상 의무의 수범자가 아니다.

**금지 조항 존재 여부:**

- 크롤링·스크래핑·자동화 수집 금지 조항 → **없음**
- 자료의 복제·배포·전송 금지 조항 → **없음**
- 사이트 콘텐츠·데이터의 저작권 귀속 조항 → **없음** (제10조는 *이용자가 게시한 게시물*의 저작권만 규정)

오히려 자료의 외부 이용을 **전제하는** 문구가 있다:

> 제9조 1항 — "서비스를 통하여 **얻은 자료로 인한 손해**에 관하여 책임을 지지 않으며"
> 제15조 3항 — "**서비스 자료에 대한 취사선택 또는 이용**으로 발생하는 손해 등에 대해서는 책임을 지지 않습니다"

자료 취득·이용을 상정하고 **면책만 규정**한다. 금지가 아니다.

**단, 주의할 조항 하나:**

> 제12조 2항 — "회원은 산림조합중앙회 산림경영지원 사이트의 **사전 승낙 없이 서비스를 이용하여 어떠한 영리행위도 할 수 없습니다.**"

- 수범자가 **회원**이므로 현재는 적용되지 않는다
- 그러나 **① 회원가입을 하는 순간** 또는 **② 오송이가 영리화(광고·유료화)하는 순간** 쟁점이 된다
- **→ 실무 결론: 데이터 수집 목적으로 회원가입을 하지 말 것.** 가입은 이득이 없고 제12조 2항만 떠안는다
- **→ 영리화 계획이 생기면 반드시 사전 승낙을 받을 것**

**약관의 한계:** 시행일이 **2008년 1월 21일**로, 크롤링·오픈API 논의 이전에 작성됐다. 자동수집 금지가 없는 것은 허용의 표현이라기보다 **당시 상정 범위 밖**이었기 때문으로 보는 것이 타당하다. 즉 "약관에 없음"을 허가로 확대 해석하면 안 된다.

**제3조**가 이를 뒷받침한다 — "이 약관에 명시되지 아니한 사항에 대해서는 ... **프로그램보호법 및 기타 관련 법령의 규정에 의합니다.**"
→ 약관이 침묵하는 영역은 **저작권법으로 넘어간다.** 이것이 2-5로 이어진다.

### 2-3. 저작권 표기 / 공공누리 ❌ (확정)

페이지 HTML 원문을 직접 확인(EUC-KR 디코딩 후 문자열 검색)한 결과:

| 검색어 | 결과 |
|--------|------|
| `공공누리` | **0건** |
| `KOGL` | **0건** |
| `저작권` (별도 정책 페이지 링크) | **0건** |
| `COPYRIGHT` | 1건 — `COPYRIGHT @ NATIONAL FORESTRY COOPERATIVE FEDERATION. ALL RIGHTS RESERVED` |

**→ 공공누리 미적용. 개방 라이선스가 부여되지 않았다.**
표시된 것은 `ALL RIGHTS RESERVED`, 즉 **전체 권리 유보** 하나뿐이다.

이는 당초 기대했던 "제1유형이면 리스크 소멸" 경로가 **없다**는 뜻이다. 남은 해소책은 담당자의 개별 허락뿐이다.

> 참고: 1차 조사에서 "푸터에 공공누리 마크 언급"이라는 관측이 있었으나, HTML 원문 검증 결과 **오탐**이었다.

### 2-4. 공식 개방 API ❌

검색 범위 내에서 공공데이터포털에 송이 공판 시세 관련 API·파일데이터는 확인되지 않았다.
산림청 데이터(산림자원통계, 산림사업법인 등)는 존재하나 **산림조합중앙회의 임산물 공판 실적은 별개**다.

→ 크롤링을 대체할 공식 경로가 없다. 따라서 담당자 문의의 가치가 더 크다(**개방 요청 자체가 정당한 요구**).

### 2-5. 데이터베이스제작자의 권리 ⚠️ — 실질 쟁점

약관을 통과해도 남는 문제. 저작권법 제4장(제91~98조).

**(a) 데이터 자체는 저작물이 아니다**
등급별 단가·거래량은 **사실 정보**다. 창작성이 없어 저작물로 보호되지 않는다. 이 점만 보면 문제가 없다.

**(b) 그러나 데이터베이스제작자의 권리는 별개다**
창작성이 없어도, 소재의 수집·검증·갱신에 **상당한 투자**를 한 자는 그 DB의 **전부 또는 상당한 부분의 복제·전송을 금지할 권리**를 가진다. 전국 조합의 일별 공판 실적을 13년간 집계·게시하는 것은 "상당한 투자"에 해당할 가능성이 높다.

**(c) 오송이의 노출도**

| 요소 | 상태 | 평가 |
|------|------|------|
| 수집 범위 | 2013~현재 **전체** | "상당한 부분"에 명백히 해당 |
| 재배포 | 통합 데이터셋을 공개 정적 파일로 제공 | 복제 + 전송 모두 해당 |
| 목적 | 비영리 개인 서비스 | 완화 요소이나 면책은 아님 |

**→ 약관보다 이쪽이 실질 리스크다.** 특히 `complete-dataset.json` 을 그대로 공개 URL로 노출하는 구조는 "원본 DB의 상당한 부분을 그대로 전송"에 가장 가깝다.

**(d) 완화 방향** (담당자 회신 전까지의 실무 조치)

- **가공·집계 형태 위주로 제공** — 원본 재현이 아니라 분석 결과라는 성격을 강화
- 출처·비영리 명시, 원본 사이트로의 링크 병기
- 영리화 보류
- **담당자 사전 양해가 가장 확실한 해소책** (4장 문의)

**(e) 공공누리 경로는 닫혔다**
공공누리가 적용됐다면(특히 제1유형) 이 쟁점이 소멸했겠지만, 2-3에서 **미적용으로 확정**됐다.
→ **DB제작자 권리 리스크를 해소할 수 있는 유일한 경로는 담당자의 개별 허락이다.** 4장 문의의 비중이 그만큼 커졌다.

## 3. 판단

### 3-1. 리스크 재배치

당초 "약관 회색지대"로 봤으나, 전문 확인 후 **리스크의 위치가 바뀌었다.**

| 경로 | 리스크 | 근거 |
|------|--------|------|
| robots.txt 위반 | **없음** | 수집 경로 허용 |
| 약관 위반 | **낮음** | 회원 약관이며 당사자 아님. 금지 조항도 없음 |
| 저작권(데이터 자체) | **낮음** | 사실 정보, 창작성 없음 |
| **데이터베이스제작자의 권리** | **중간** | 전체 수집 + 원본 형태 재배포 |
| 개방 라이선스로 인한 면책 | **없음** | 공공누리 미적용 확정 (2-3) |
| 영리화 시 | **상승** | 약관 제12조 2항 + DB권리 이중 |

**→ 지금 당장 서비스를 중단해야 할 수준의 위반은 확인되지 않았다.** 다만 `complete-dataset.json` 을 원본 형태로 공개 전송하는 구조가 가장 노출도가 높다.

**공공누리 미적용이 확정되면서 자동 해소 경로가 사라졌다.** 담당자 문의가 선택이 아니라 **필수 단계**가 됐다.

### 3-2. 즉시 적용할 조치

| 조치 | 상태 | 비고 |
|------|------|------|
| 출처 명시 (사이트 푸터 + README) | 미적용 → 즉시 | 원본 페이지 링크 병기 |
| 비상업 서비스임을 명시 | 미적용 → 즉시 | |
| 운영자 연락처 공개 | 미적용 → 즉시 | 중단 요청 창구 |
| 중단 요청 시 즉시 대응 방침 명문화 | 미적용 → 즉시 | |
| **데이터 수집용 회원가입 하지 않기** | 유지 | 가입 시 제12조 2항을 떠안음 |
| **영리화(광고·유료) 보류** | 유지 | 사전 승낙 없이는 불가 |
| 수집 주기 적정성 | 시즌 중 매시간(10~22시) | 문의 시 함께 확인 |
| **담당자 문의** | **미발송 (4장 초안)** | |

문의는 **허가를 구하는 동시에 리스크를 줄이는 행위**다. 사전에 알리고 회신이 없거나 문제 제기가 없으면, 사후에 문제가 되더라도 선의를 입증할 근거가 된다.
