8. **끝 라벨 충돌** (추이·지역별): 강원과 경남 끝 라벨이 거의 겹친다(`years=2025&by=region&metric=unitPrice`). 세로로 밀어내는 처리가 필요하다.
9. **경남 보라색이 다크 모드에서 어둡다** — 추이 선과 칩 점이 배경에 묻힌다.

11. **과거 연도 선이 모두 같은 회색** (연도 겹침) — 툴팁 색 표시도 전부 같은 회색이라 끝 라벨 말고는 어느 선이 몇 년인지 알 수 없다. 명도를 단계별로 다르게 하거나, 호버한 선을 강조한다.
12. **진행 중 시즌 구분 없음** (등급 구성·시즌 요약): 2026(3일) 막대와 행이 완결된 시즌과 똑같은 무게로 보인다. "진행 중" 표시를 붙이거나 흐리게 한다.

## C. 큰글씨 모드 — ✅ 완료 (2026-09-21, `feat/analysis-polish`)

13. 분석 페이지에서는 크기가 들쭉날쭉하게 커진다.
    - 제목 "데이터 분석"이 부제목(2013–2026 · …)보다 작아진다.
    - 컨트롤 라벨(지표·단위·정렬), "전체 조합", "공통 조합만"은 커지지만 세그먼트 버튼, 뷰 탭, 필터 칩, 차트 축은 그대로다.

처리 방식: 큰글씨 모드를 **루트 글자 크기 확대(16→19px)**로 바꿨다.
`App.css`가 variant마다 크기를 `!important`로 고정하던 탓에 sx로 직접 지정한 제목이 본문 규칙에 덮여 부제목보다 작아졌고,
규칙이 없는 탭·칩·세그먼트는 아예 커지지 않았다. 고정 규칙을 걷어내니 rem 기반 크기가 모두 비례해 커진다.
버튼·아이콘 최소 크기와 표 패딩은 터치 타깃이라 그대로 뒀다.
px로 그리는 SVG 차트는 `scaleFont`·`scaleMargin`·`scaleLength`(배율 1.2)로 그릴 때 직접 키우고,
`displayMode`를 draw 훅 의존성에 넣어 토글 즉시 다시 그린다.

14. 가로 스크롤 영역(템플릿 카드, 뷰 탭, 시즌 요약 표)에 끝 페이드나 그림자가 없다.
    탭은 "관계"까지만 보여서 "커버리지"와 "표"가 있는지 모른다.

처리 방식: 공통 `ScrollFade`(+ `useScrollEdges`)로 아직 볼 내용이 남은 쪽만 흐리게 한다 — 템플릿 카드·뷰 탭·표에 적용.
표는 고정 첫 열을 가리지 않도록 왼쪽 페이드를 끈다(`fadeStart={false}`). 첫 열 고정은 이미 되어 있었다.
뷰 탭은 선택이 바뀌면 해당 탭을 스크롤해 보여 준다(템플릿으로 뷰가 바뀌어도 어디 있는지 보인다).

## E. 사소 — ✅ 완료 (2026-09-21, `feat/analysis-polish`)

15. URL에 빈 파라미터가 남는다: `regions=&unions=`, `compare=none`, `common=0` → 기본값은 생략해서 공유 링크를 짧게.
16. 조합 선택 팝오버의 조합 순서가 가나다순이 아니다 (강원: 홍천, 양구, 인제, 고성, 양양…).
17. 관계 차트의 y축 제목 "단가"가 세로로 작게 붙어 있어 거의 보이지 않는다. 맨 위 격자선에는 눈금 라벨이 없다.

처리 방식 요약:
- 15 기본값과 같은 키는 직렬화에서 생략(`view`·기간은 항상 명시). 분석 파라미터가 하나라도 있는 URL이면 빠진 키를
  기본 템플릿이 아니라 고정된 정적 기본값으로 읽어, 기본 템플릿이 바뀌어도 옛 공유 링크가 같은 화면을 연다.
  예전 링크의 `grades=all`도 계속 전체 등급으로 읽는다.
- 16 팝오버 목록만 가나다순 정렬 — 조합 색은 `REGION_UNION_MAP` 순서를 쓰므로 원본 순서는 건드리지 않았다.
- 17 y축 제목을 플롯 위 왼쪽에 가로로 두고 단위를 붙였다("단가 (만원/kg)"). x 눈금도 축 최댓값 기준으로 kg·톤을 통일.
